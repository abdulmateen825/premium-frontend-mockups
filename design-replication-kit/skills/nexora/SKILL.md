# Nexora design replication

Detailed prompt: [`../../prompts/nexora.md`](../../prompts/nexora.md). Workspace reference: `nexora/`.

## Workflow

1. Inspect repository guidance, entry point, styles, dependencies, breakpoints and assets. Preserve product meaning and conventions.
2. Establish charcoal, warm-white, muted gray, restrained coral and violet tokens; Hanken Grotesk prose and IBM Plex Mono metadata. Use hairlines, a technical grid and quiet density, not a generic AI gradient.
3. Implement the full page: system-status hero, connected-tool strip, inline-chip capabilities, three-step Method with synchronized workflow preview, HTML dashboard, expandable ecosystem diagrams, quote, warm CTA and footer.
4. If recreating the ribbon, use native WebGL2 as in reference. Cap DPR, pause offscreen, resize safely, clean up, provide CSS fallback and render a static reduced-motion frame. No Three.js or screenshot mockups.
5. Method state responds to intersection and usable controls, not hover alone. Build product previews in responsive HTML/SVG.
6. Keep scroll effects restrained; collapse nav/columns and preserve dashboard legibility at phone widths. Label illustrative metrics honestly.
7. Review full composition and describe limitations accurately. No tests unless requested.

## Preserve

- Credible editorial voice; human approval and traceability are core themes.
- Status metadata, whitespace and restrained coral/violet.
- Canvas cleanup, offscreen pause, failure fallback and lower mobile cost.
- Never present fabricated dashboard activity as actual outcomes.
